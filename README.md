# 公众号排版

免费、无需登录的公众号图片排版工具。

## 在线使用

[打开公众号排版](https://lanlingmu.github.io/gongzhonghao-paiban/)

网址：https://lanlingmu.github.io/gongzhonghao-paiban/

## 功能

支持拖动排序、逐行1/2/3列、公众号HTML批量提取微信图片地址、上下表情、保存/恢复JSON、复制富文本及导出HTML。

内容在浏览器本地处理，不上传到本项目服务器；在线图片由相应图片服务提供。仓库不包含用户草稿、图片地址、聊天记录或角色图片。

公众号可能过滤CSS，正式发布前请保存草稿并手机预览。pointer-events不是防下载功能。

## 本地使用

下载仓库后打开index.html，保持layout-core.js在同一目录。

main分支根目录通过GitHub Pages发布，后续代码提交后会自动更新网站。
